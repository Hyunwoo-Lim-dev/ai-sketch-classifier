# AI Sketch Classifier

## 1. 프로젝트 개요
Google의 Quick, Draw! 데이터셋과 TensorFlow, Keras를 활용하여 사용자가 그린 그림을 자동으로 분류하는 인공지능 모델을 개발하였다.

## 2. 개발 목적
CNN(합성곱 신경망)을 활용한 이미지 분류 모델의 학습 과정을 이해하고, 학습된 모델을 이용하여 새로운 그림을 예측하는 것을 목표로 한다.

## 3. 개발 환경
- 언어: Python
- 개발 환경: Google Colab
- 딥러닝 프레임워크: TensorFlow, Keras
- 데이터셋: Google Quick, Draw!

## 4. 분류 대상
1. Apple (사과)
2. Bicycle (자전거)
3. Cat (고양이)
4. House (집)
5. Star (별)

## 5. 주요 기능
- Quick, Draw! 데이터셋 다운로드
- 이미지 데이터 전처리
- CNN 모델 구성 및 학습
- 학습 정확도 및 손실 그래프 출력
- 사용자가 직접 그린 그림의 종류 예측

## 6. 실행 결과
학습된 모델을 이용하여 사용자가 그린 그림을 분석하고, 사과·자전거·고양이·집·별 중 하나로 분류한다.

## 7. 실행 방법
1. AI_Sketch_Classifier.ipynb 파일을 Google Colab에서 연다.
2. 셀을 위에서부터 순서대로 실행한다.
3. 모델 학습이 완료되면 그림 그리기 기능을 이용한다.
4. AI 예측 버튼을 눌러 분류 결과를 확인한다.
